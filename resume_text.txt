AI Platform & Systems (2022–Present)
AI Expert Marketplace Platform
Built an end-to-end platform that matches vetted AI experts with clients — the core challenge
being trust and relevance at scale, solved entirely through AI.
Multi-model expert evaluation engine Designed a LangChain-orchestrated pipeline that routes
expert profiles across multiple open-source models (LLaMA, Mistral) and proprietary APIs (GPT,
Gemini) for parallel evaluation. Each model assesses different dimensions — technical depth,
domain specificity, communication clarity — and results are aggregated into a structured scoring
rubric. The multi-model approach was deliberate: no single model consistently outperformed
across all expert types, so ensemble scoring significantly reduced evaluation blind spots.
Fraud detection & ID verification system The hardest problem on the platform — fake credentials
and profile manipulation are sophisticated and varied. Built a hybrid detection pipeline: LLM-based
document and profile analysis to catch semantic inconsistencies (e.g. credential dates that don't
add up, descriptions that pattern-match known fabrications), layered with ML anomaly detection
models trained on behavioral signals (account creation patterns, edit history, response timing). This
two-layer approach catches both obvious fraud and subtle edge cases that rule-based systems
miss entirely.
Semantic expert–client matching engine Replaced keyword-based search with a RAG-powered
matching system using vector embeddings (Pinecone / Weaviate). Client requirements are
embedded and matched against expert profiles by semantic similarity — capturing intent and
context rather than surface-level keyword overlap. Result: matches that reflect what clients actually
need, not just what they typed.
End-to-end ownership Designed system architecture, built backend APIs, implemented AI pipelines,
delivered frontend UX, and deployed on AWS. Sole AI engineer for the platform's core intelligence
layer.
